winver, but for Linux

## Install
### any distro:
1. install dependencies:
*Arch-based*:
```bash
sudo pacman -S qt6-base 
```

*Debian-based*:
```bash
sudo apt update && sudo apt install -y qt6-base-dev 
```

*Fedora*:
```bash
sudo dnf install -y qt6-qtbase-devel 
```

2. install [linver](https://github.com/itsflameee/linver/releases)

3. run linver:
```bash
linver
```

### Arch Linux
```bash
yay -S linver 
```
or
```bash
paru -S linver 
```
